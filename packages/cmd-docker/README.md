# @ac-kit/cmd-docker

This package provides a set of reusable utilities and wrappers for working with
CLI commands and processes in Node.js and TypeScript projects. It's designed to
help you build robust, scriptable command-line tools and automate system tasks,
with a focus on composability and reliability.

## Installation

You can install the package via npm:

```bash
npm install @ac-kit/cmd-docker
```

Or via yarn:

```bash
yarn add @ac-kit/cmd-docker
```
