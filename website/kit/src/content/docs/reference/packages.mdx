import { DOMAINS, domainPackages } from "../../../lib/packages.js";
import { documentedPackages } from "../../../lib/api.js";

export const documented = new Set(documentedPackages());

The guide is organised by subject rather than by package, so this page is the
bridge: it is how you get from a package name you already have — in an error
message, in a `package.json`, in somebody else's import — to the pages that
explain it.

Install any of them with your package manager of choice; every name below is
published under the `@ac-kit` scope.

**Portable** packages import no host built-ins and run under Node, browsers,
Deno, Bun and edge runtimes alike. **Node only** packages are bound to a host,
and a portable package will never depend on one.
